# NetTrigger 人性化交互与极致易用度设计规范

> 本文档规范 NetTrigger 在用户交互、视觉反馈、配置引导、故障诊断及日常免打扰体验方面的设计标准，确保软件既有硬核极致的性能，又具备“小白友好”的零门槛体验。

---

## 1. 核心人机工程理念 (User Experience Principles)

1. **“双击即用，零配置启动”原则**：
   - 用户第一次双击 `NetTrigger.exe` 时，程序绝不抛出任何弹窗错误。
   - 自动在同一目录下检测是否存在 `config.toml`；若不存在，系统**原子化自动生成带有详尽中文说明的标准模板**，并给出友好的托盘提示。
2. **“打游戏零打扰，状态尽在掌握”原则**：
   - 默认模式下，网络掉线时后台**纯静默完成认证**，不弹窗、不夺取焦点、不发出声音。
   - 提供丰富直观的系统托盘（System Tray）视觉反馈，鼠标一扫即可看清当前网络延迟、连通状态与历史重连日志。
3. **“傻瓜式认证导入”原则**：
   - 针对普通用户对 HTTP 表单抓包望而生畏的问题，支持**浏览器 cURL 命令一键直接导入**与**参数宏替换**，大幅降低使用门槛。

## 2. 系统托盘交互全景设计 (System Tray & Visual Feedback)

### 2.1 四态高辨识度托盘图标与状态指示

系统托盘图标采用现代矢量风格高对比度色彩设计，即便在 Windows 10/11 的深色/浅色任务栏背景下均清晰醒目：

| 图标状态 | 视觉形态 | 对应网络状态 | 鼠标悬停 Tooltip 示例文本 |
| :--- | :--- | :--- | :--- |
| 🟢 **在线 (Online)** | 纯净绿色脉冲圆环 | 互联网畅通，未受拦截 | `NetTrigger - 网络畅通`<br/>`延迟: 12ms | 运行: 3小时25分` |
| 🟡 **认证中 (Authenticating)** | 明亮金黄色旋转指示 | 检测到网络拦截，正在静默重连 | `NetTrigger - 正在尝试自动认证...`<br/>`尝试次数: 1 | 阶段: 发送报文` |
| 🔴 **离线 (Offline)** | 警示红色实心圆点 | 物理断网 / 认证多次失败进入冷却 | `NetTrigger - 网络断开 / 认证未成功`<br/>`提示: 右键托盘可手动重试或查看详情` |
| ⚪ **免打扰/暂停 (Paused)** | 优雅半透明灰色 | 用户手动暂停了自动守护 | `NetTrigger - 已暂停守护` |

### 2.2 托盘上下文右键菜单体系

托盘右键菜单设计遵循**“高频操作置顶、低频配置靠后、分组清晰”**的交互规范：

```
+------------------------------------+
| ⚡ 立即检测并重新认证               |  <- 遇到网络卡顿，用户最想做的一键重试
| 🌐 打开网络认证网页 (Browser)       |  <- 兜底快速通道
|------------------------------------|
| ⚙️ 编辑配置文件 (config.toml)       |  <- 点击直接调用系统默认编辑器打开
| 🧪 一键测试当前认证配置             |  <- 无需等断网，立即验证账号密码接口是否有效
|------------------------------------|
| [√] 开机自启动                     |  <- 点击即勾选/反选，实时修改注册表
| [√] 静默模式 (游戏免打扰)          |  <- 开启后成功重连绝不弹系统通知气泡
| 📊 查看运行状态与诊断日志           |  <- 弹出极简状态小窗口或打开最近日志
|------------------------------------|
| 🚪 退出 NetTrigger                 |
+------------------------------------+
```

## 3. 极简人性化配置体系 (`config.toml`)

### 3.1 自动生成与注释说明
首次启动生成的默认配置文件，所有键名具有自解释性，且附带完整的真实场景注释：

```toml
# ==============================================================================
# NetTrigger 配置文件
# 修改保存后，右键托盘图标点击【一键测试当前认证配置】即可验证！
# ==============================================================================

[general]
# 托盘中显示的应用名称
app_name = "NetTrigger"

# 正常网络畅通时的探针心跳间隔（单位：秒，建议 30 ~ 60，避免浪费系统资源）
heartbeat_interval_sec = 45

# 是否开启 Windows 系统级网络变动监听（0 延迟即刻重连，强烈建议保持 true）
enable_zero_latency_watcher = true

# 静默免打扰模式：true 时即使重连成功也不弹出系统通知，打游戏推荐开启
silent_mode = true

# 连续失败时的最大退避等待时间（秒，防止频繁重发导致校园网封号或机房过载）
max_backoff_sec = 60


# ==============================================================================
# 网络连通性探针配置（通常保持默认即可，已针对国内网络深度优化）
# ==============================================================================
[probe]
# 首选探测地址（采用超低延迟的标准 204 无内容端点）
primary_url = "http://connect.rom.miui.com/generate_204"

# 备用探测地址（Windows 官方连通性测试端点）
fallback_url = "http://www.msftconnecttest.com/connecttest.txt"
fallback_expected_keyword = "Microsoft Connect Test"

# 单次探测超时时间（毫秒）
timeout_ms = 3000


# ==============================================================================
# 自动认证动作配置
# 模式选择：
#   "http"    - 【推荐】后台全静默登录，无需打开浏览器，完全无感（需配置下方 [auth.http]）
#   "browser" - 【极简】掉线时自动在系统浏览器打开登录网页，由浏览器记住密码自动登录
# ==============================================================================
[auth]
mode = "http"

# 校园网/公共网登录门户网页 URL（浏览器模式或右键菜单使用）
portal_url = "http://portal.example.edu/"

# ------------------------------------------------------------------------------
# 静默 HTTP 认证配置（仅在 mode = "http" 时生效）
# 提示：在浏览器登录页面按 F12 -> Network(网络) -> 点击登录 -> 右键登录请求
#       查看 Request URL 与 Payload 参数，填入下方即可！
# ------------------------------------------------------------------------------
[auth.http]
# 请求方法：POST 或 GET
method = "POST"

# 登录接口真实提交地址（非网页地址，通常带有 /login 或 /drcom 等后缀）
action_url = "http://portal.example.edu/api/login"

# 登录提交的表单参数（键值对形式）
# 支持智能动态宏变量：
#   {username} - 自动替换为上方用户配置
#   {password} - 自动替换为上方密码配置
#   {ip}       - 自动获取本机当前内网 IP
#   {time}     - 自动填充当前 13 位毫秒时间戳
[auth.http.params]
username = "your_username_here"
password = "your_password_here"
# 如果你的校园网需要选择运营商（例如: cmcc/unicom/telecom），可在此增加字段:
# domain = "telecom"

# HTTP 请求头（可选，防被反爬校验）
[auth.http.headers]
User-Agent = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
Content-Type = "application/x-www-form-urlencoded"
```

## 4. 故障诊断与自愈功能 (Self-Healing & Diagnostics)

1. **一键配置健康检查（Config Sanity Check）**：
   - 用户从托盘菜单点击“一键测试当前认证配置”时：
     - 系统在后台异步发送一次认证请求；
     - 捕获网关返回的响应状态码及简短回复（如 `{"result": 1, "msg": "login_ok"}`）；
     - 通过托盘气泡或轻量消息框向用户明确提示：`✅ 认证配置有效！网关返回成功` 或 `❌ 认证失败：用户名或密码错误 (HTTP 401)`。
   - **价值**：用户无需拔网线或等掉线，即可立刻确认自己的配置是否正确。
2. **免管理员权限的开机自启（Clean Autostart）**：
   - 不创建复杂的 Windows 计划任务，不请求 UAC 管理员提权。
   - 纯净写入 Windows 当前用户注册表：  
     `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
   - 写入路径为当前可执行程序的**绝对规范路径**（附带防空格转移引号）。
   - 用户右键托盘随时一键开启或关闭。
3. **自愈与路径脱敏**：
   - 无论用户从快捷方式、命令行、开机自启或是特定目录双击打开，NetTrigger 第一时间锁定宿主程序所在物理目录。
   - 彻底摆脱工作目录不一致导致的文件找不到问题。
