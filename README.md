# NetTrigger ⚡

[English](README_EN.md) | **简体中文**

**专为 Windows 平台打造的原生、超轻量（RAM < 2MB）、毫秒级事件响应的网络状态感知与校园网自动化重连守护引擎**

> **NetTrigger** 告别传统脚本 1~2 秒高频死循环轮询与粗暴弹窗切屏。NetTrigger 接入 Windows 原生网络内核通知，在掉线或网络变更的瞬间（毫秒级）被动唤醒并后台静默完成认证，**让打游戏、全屏观影与远程会议全程流畅、零弹窗、零掉帧、零感不断流**。

### 步骤 2：配置认证与网关说明

支持两大场景一键切换：**校园网** 与 **公用网络**。

#### 模式 A：网页自动登录 / 记住密码 (默认推荐 ⭐)
若你的网络支持在浏览器中记住密码自动登录：
1. 鼠标**左键单击**或**右键**点击托盘图标 ➔ 点击 **【设置】**；
2. 填入你的认证登录网页 URL（若不确定可直接留空，NetTrigger 断网被拦截时会自动捕捉并填充）；
3. 点击 **【保存设置】** 即可。

#### 模式 B：后台静默自动连 (电竞极速免切屏)
若追求打联机游戏 100% 保持前台焦点、绝不弹出任何浏览器窗口：
1. 打开 **【设置】** ➔ 切换至 **【后台自动连 (推荐·无弹窗不切屏)】** 标签页；
2. 在浏览器登录页面按 `F12` 复制 cURL 命令，粘贴到输入框一键智能解析填入；
3. 点击 **【测试连接】** 确认网关返回成功 ➔ 点击 **【保存设置】**。

## ⚡ 核心技术特性

```mermaid
flowchart LR
    A[Windows IP Helper 内核通知] -->|< 5ms 被动唤醒| B[50ms 黄金链路防抖]
    B --> C[权威 204 探针检测]
    C -->|发现网关拦截| D[后台静默 HTTP / 网页平滑认证]
    D -->|二次快速核验| E[🟢 瞬间恢复连通 (总耗时 < 95ms)]
    style E fill:#22c55e,stroke:#15803d,color:#ffffff
    style D fill:#0284c7,stroke:#0369a1,color:#ffffff
```

1. **电竞级毫秒响应 · 50ms 黄金防抖**：挂钩 Windows 原生 IP Helper API（`NotifyAddrChange`），物理网卡重新插拔或 WiFi 重连瞬间毫秒级激活。50ms 链路微等待确保本地 DHCP 路由生效，杜绝无效发包。
2. **绝对防夺焦保护 (Zero-Focus Stealing)**：纯后台网络通信，全屏竞技游戏与远程会议绝不失去鼠标焦点、绝不切屏卡顿。
3. **按需瞬态微型 Web 控制中心**：不内置任何重型浏览器引擎。点击【⚙️ 设置】时随调随开，保存配置或 5 分钟空闲后自动关闭端口并释放资源，内存秒回 1.8MB。
4. **工业级防崩溃保证**：全流程零未保护的 `unwrap()` 或 `expect()`，单实例命名互斥体防多开，开机自启安全读写当前用户注册表。

## 🖥️ 托盘视觉与操作说明

### 状态灯指示（纯内存动态矢量渲染，不依赖外部图标文件）
- 🟢 **翠绿色**：`网络已连接`（鼠标悬停 Tooltip 显示当前往返延迟，如 `延迟: 12ms`）
- 🟡 **金黄色**：`正在连接网络...` 或 `需要登录校园网`
- 🔴 **警示红**：`未连接到网络 (WiFi/网线未插)` 或 `网络连接稍后重试...`
- 🔵 **天空蓝**：`正在启动...`

### 托盘交互捷径
- **鼠标左键单击 / 双击**：直接打开 **【设置】** 控制中心；
- **鼠标右键单击**：展开简洁无冗余的操作菜单：
  ```
  +------------------------------------+
  | 立即重连                           |  <-- 手动立即强制重测并重连
  | 打开登录网页                       |  <-- 浏览器快速登录通道
  |------------------------------------|
  | 设置                               |  <-- 打开极简控制中心 (左键亦可打开)
  | Language / 语言          ▶         |  <-- 原生就地切换子菜单 (Auto / English / 简体中文)
  |------------------------------------|
  | [√] 开机自启动                     |  <-- 点击切换开机自启 (免管理员提权)
  | [√] 静默模式 (免打扰)              |  <-- 开启后连网成功不弹任何通知气泡
  |------------------------------------|
  | 退出                               |
  +------------------------------------+
  ```

## 🛠️ 本地编译与构建

基于标准 Rust 工具链（Edition 2021）：

```powershell
# 1. 克隆代码仓库
git clone https://github.com/Sacilave/net-trigger.git
cd net-trigger

# 2. 运行自动化全链路测试套件 (包含 36 项单元与 Mock 边界测试)
cargo test

# 3. 极限裁剪编译 (自动应用 LTO、Strip 符号剥离与尺寸优化)
cargo build --release

```
